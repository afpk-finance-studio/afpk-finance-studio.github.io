시작하기 전에,
서로 약속부터 정해요

재무설계의 첫 단계는 계산이 아니라 약속입니다. 무엇을 도와드리고 무엇은 하지 않는지, 누가 무엇을 맡는지 먼저 정하고 시작합니다.

상담은 이렇게 진행돼요

지금은 6단계 중 첫 번째, 약속을 정하는 단계입니다

  1. 01약속 정하기도와드릴 범위와 역할을 정해요
  2. 02내 정보 알려 주기소득·지출·자산·목표를 적어요
  3. 03지금 상태 진단잘하는 점과 부족한 점을 봐요
  4. 04설계안 받기목표별로 돈을 나눠 담아요
  5. 05실행하기자동이체와 할 일을 챙겨요
  6. 06정기 점검상황이 바뀌면 다시 맞춰요

이 상담에서 해 드리는 것

김민준님 같은 직장인의 돈 관리를 처음부터 끝까지

  • 내 돈 흐름을 한 장으로 정리

    매달 들어오고 나가는 돈, 가진 것과 갚을 것을 표로 보여 드려요

  • 새는 지출을 찾아 저축할 돈 만들기

    줄일 수 있는 지출과 그만큼 늘어나는 저축액을 알려 드려요

  • 목표별로 통장 나누기

    비상금, 전세 보증금, 내 집 마련, 노후 자금을 따로 모아요

  • 세금 혜택 챙기기

    ISA, 연금저축, 청년도약계좌처럼 세금을 아끼는 통장을 연결해요

해 드리지 않는 것

고객님께 불리할 수 있는 일은 처음부터 하지 않아요

  • 특정 주식·코인 종목 추천

    "이 종목 사세요"가 아니라 어떤 통장에 얼마를 모을지를 설계해요

  • 금융상품 판매나 가입 대행

    상품을 팔아 수수료를 받지 않아요. 가입은 고객님이 직접 하세요

  • 세금 신고 대행

    연말정산이나 종합소득세 신고는 세무 전문가의 일이에요

2. 미래가치는 어떤 식으로 계산하나요?
적립식 복리 (매월 말 납입)FV = PMT × [(1 + r)ⁿ − 1] ÷ r
거치금 복리FV = PV × (1 + r)ⁿr = 연 기대수익률 ÷ 12, n = 개월 수. 성장 경로는 매월 잔액 × (1 + r) + 납입액으로 반복 계산합니다.
